Temporary private relay for the official Proxmox VE 9.2-1 x86-64 installer used by the VCS Proxmox POC.

- Official source: `https://enterprise.proxmox.com/iso/proxmox-ve_9.2-1.iso`
- Expected SHA256: `4e88fe416df9b527624a175f24c9aa07c714d3332afb1ee3dbf3879573ef2c6c`
